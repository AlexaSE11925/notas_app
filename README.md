# Aplicación de Notas - Línea de Énfasis II

Aplicación móvil desarrollada en Flutter que permite registrar usuarios, iniciar sesión y gestionar notas con funcionamiento online y offline.

## Funcionalidades

- Registro de usuarios
- Inicio de sesión con autenticación JWT
- Crear notas
- Consultar notas
- Editar notas
- Eliminar notas
- Persistencia local con SQLite
- Funcionamiento sin conexión
- Sincronización automática al recuperar conexión
- Consumo de API REST mediante GET, POST, PUT y DELETE

## Tecnologías utilizadas

- Flutter
- Dart
- SQLite
- Node.js
- Express
- JWT
- HTTP
- Connectivity Plus
- Flutter Secure Storage
